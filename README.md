# Diverse Thinking · 多元思维模型工坊

学习与辅助运用用的网页：把常用思维模型写成可检索、可跳转、可练习的格子。

清单来源之一：`104模型.txt` 中的 104 条（芒格常提模型 + SMART / SCQA / 四象限 / 情绪ABC）。与馆内已有条目重合的合并为同一模型（用别名检索），其余按同一格式补入。馆内另保留第一性原理、二阶思维、期望值等清单未单列但常用的骨干模型。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里提示的本地地址（默认 `http://localhost:5177`）。

```bash
npm run build
npm run preview
```

## 怎么用

1. **学**：模型馆按八个领域浏览。每条包含一句话定义、隐喻、机制、步骤、何时用/不用、陷阱、运用清单、自问、固定五段案例。来自 104 清单的条目带「芒格104」标签。
2. **连**：模型之间有互补、制衡、对照、先修关系；关系图可按领域筛选；对照页并排阅读；组合拳按顺序带上多个模型。
3. **用**：情境入口从问题出发推荐模型；运用工作台按清单填写，记录存在本机书桌。

## 内容结构

| 区块 | 含义 |
| --- | --- |
| 决策判断 | 第一性原理、逆向、机会成本、决策树、证伪、五Why、四象限等 |
| 系统演化 | 复利、反馈、瓶颈、临界点、冗余、路径依赖、蝴蝶效应等 |
| 概率不确定 | 贝叶斯、基础比率、肥尾、灰犀牛、均值回归、正态分布等 |
| 激励与交换 | 激励、博弈、比较优势、马太效应、信息不对称、规模效应等 |
| 认知纠偏 | 确认偏差、锚定、框架、光环、群体思维、双系统、情绪ABC等 |
| 学习成长 | 费曼、帕累托、金字塔、SMART、SCQA、六顶帽、需求层次等 |
| 战略与组织 | 定位、价值链、核心竞争力、SWOT、平衡计分卡、权力距离等 |
| 科学类比 | 库仑类比、生态位、能量守恒、信息熵 |

案例格式统一为：**情境 → 直觉反应 → 模型切入 → 行动 → 启示**。

书桌数据保存在浏览器 `localStorage`，不会上传。
